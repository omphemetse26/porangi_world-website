# Changelog

All notable changes to the Porangi World website project are documented in this file.

## [2026-11-02]

### Added
- Created a new enquiry page with a quote calculator, live search, and gallery lightbox.
- Added a responsive, colorful styling system for the website.
- Added SEO files:
  - `robots.txt`
  - `sitemap.xml`
- Added a functional live search bar to the enquiry page.
- Added a lightbox gallery for menu and food images.

### Fixed
- Corrected broken image paths so the logo and food images show correctly when served locally.
- Fixed stylesheet and JavaScript paths for all pages so they work in Live Server.
- Fixed navigation links and page structure across the project.
- Fixed a broken `location.html` page so the map displays correctly.
- Fixed `aboutus.html` and `contact.html` layout and path issues.

### Improved
- Updated the website to be more readable and visually appealing.
- Improved form handling with validation for empty fields and invalid email addresses.
- Added same-page response output for enquiry and contact forms.
- Added a more professional HTML structure and page titles.

### Notes
- The website now uses a cleaner structure and more reliable relative paths for local hosting.
- Contact and enquiry forms are prepared to show messages and calculations on the same page without requiring a backend.
