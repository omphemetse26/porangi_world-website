# Porangi World

Porangi World is a colorful restaurant website for a food brand inspired by global flavors and exciting menu experiences. The project includes multiple pages for the homepage, about section, menu, contact area, enquiry form, and location map.

## Project purpose
This website was created to showcase the Porangi World brand and provide a simple online experience for visitors to:
- view the business story and mission
- browse menu items and food gallery
- submit an enquiry with a quick price estimate
- contact the business directly
- find the physical location on a map

## Pages included
- `index.html` — home page with logo and branding
- `aboutus.html` — business story and mission
- `menu.html` — menu items and food images
- `contact.html` — contact information and customer message form
- `enquiry.html` — pricing estimate form and gallery
- `location.html` — Google Maps location embed

## Features
- Responsive layout for desktop and mobile devices
- Bright modern styling and readable design
- Live search bar for content filtering
- Lightbox gallery for food images
- Enquiry form with item quantity calculation and total estimate
- Contact form with empty-field and invalid-email validation
- SEO support with `robots.txt` and `sitemap.xml`

## How to run locally
Open the project in a browser, or use a local Live Server in VS Code.

1. Open the project folder in VS Code.
2. Right-click on `index.html`.
3. Choose `Open with Live Server`.

## Notes
The project uses relative paths so that images and styles load correctly when hosted locally or served through a local web server.
